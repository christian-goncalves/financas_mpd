# Contexto para o Codex

Você está trabalhando no projeto Controle de Finanças MPD.

O objetivo é criar um PWA extremamente simples para controle de contas recorrentes da Michele e Christian.

Prioridades:

1. Simplicidade extrema.
2. Interface amigável no iPhone.
3. Sem framework no MVP.
4. HTML, CSS e JavaScript puro.
5. Integração com n8n via endpoints.
6. Google Sheets como base de dados.
7. WhatsApp via Evolution API.
8. Evitar complexidade desnecessária.

Não implementar:

- React
- Next.js
- Banco relacional
- Login completo
- Integração bancária
