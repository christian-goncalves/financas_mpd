# Questions

## Decisões respondidas

- O acesso ao PWA será por token longo/magic link, sem login no MVP.
- A lista será única para Christian e Michele.
- O app será PWA hospedado na Vercel.
- O frontend será HTML, CSS e JavaScript puro.
- Não usar React, Next.js ou framework no MVP.
- O valor principal será exibido em ARS.
- O valor convertido em BRL será exibido menor e esmaecido.
- Contas automáticas aparecerão com a etiqueta “Débito aut.”.
- Contas automáticas também poderão ser marcadas como pagas manualmente.
- O WhatsApp será enviado para um grupo específico via Evolution API.
- O n8n será self-hosted.
- Google Sheets será a base de dados do MVP.

- Definir o token de acesso do PWA.
- Identificar o groupJid do grupo WhatsApp na Evolution API.
- Definir as primeiras 5 a 10 contas do teste real.
